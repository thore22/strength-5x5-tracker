# Accessory swap policy

Researched 2026-11-07. These are conservative product decisions inferred from movement patterns and exercise descriptions, not scientifically validated equivalence pairs. Shared muscles alone do not establish an interchangeable exercise. Loading, difficulty and muscle emphasis remain different; each exercise retains its stable ID and independent progression.

Only the original accessory in the active A/B session determines the eligible group. Program edits, an accessory in the other template, or repeated swaps cannot broaden that group. The exercise must already exist in the local built-in catalog with its expected equipment type. Customized names/descriptions retain the exercise identity; changed equipment and unclassified custom IDs are excluded.

| Included accessories                     | Allowed group                    | Basis and limits                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| ---------------------------------------- | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Barbell Curl, Dumbbell Curl, Hammer Curl | Each other                       | Elbow flexion accessories. Grip changes emphasis; dumbbell load is per hand. | Pull-ups, Chin-ups                       | Each other                       | Vertical upper-body pulling with different grips. ACE places both in the [pulling workout column](https://www.acefitness.org/continuing-education/certified/december-2024/8763/the-ace-body-weight-workout-builder/). Preserve separate added-load records.                                                                                                                                                                                                                                                                                                                                                              |
| Triceps Extension, Skull Crusher         | Each other                       | Elbow extension isolation; shoulder position and equipment differ. The [ACE triceps study](https://www.acefitness.org/certifiednewsarticle/3008/ace-study-identifies-best-triceps-exercises/) describes cable push-downs and lying barbell extensions. A small acute EMG study does not establish equal long-term results.                                                                                                                                                                                                                                                                          |

## Replacement prescriptions

These are app defaults, not claims that sources mandate exact set/rep prescriptions. They apply only when selecting a replacement; restoring the original uses its captured custom prescription. Keep the original slot’s rest period. Do not import a prescription from the other workout or mutate either template.

| Replacement                                 | Sets × target     | Progression                    |
| ------------------------------------------- | ----------------- | ------------------------------ |
| All curls; triceps extension; skull crusher | 3 × 8–12 reps     | Double progression suggestions |
| Pull-ups; chin-ups                          | 3 × 5–10 reps     | Double progression suggestions |
| Hanging leg/knee raise                      | 3 × 8–15 reps     | Manual; no added load          |
| Plank                                       | 3 × 20–40 seconds | Manual; no added load          |
| Ab wheel                                    | 3 × 6–10 reps     | Manual; no added load          |
| Romanian deadlift                           | 2 × 8–10 reps     | Double progression suggestions |
| Back extension                              | 2 × 8–12 reps     | Double progression suggestions |

Loaded alternatives use their own saved target when previously performed, with explicit confirmation. Without previous performance, require an entered starting load; never reuse the replaced lift’s weight or assume the catalog’s initial load is suitable. Weighted bodyweight targets mean added load, not body mass. The replacement dialog displays previous reps and individual set loads rather than implying all prior sets used one weight.

## Storage

State/backup v3 adds an optional `SessionLift.replaced` snapshot of the originally planned exercise, prescription and working weight. Substituting an unstarted lift creates a fresh session snapshot; the original snapshot and completed records remain unchanged. Returning to the original removes substitution metadata. Groups are checked against the original rather than the last replacement. Existing v1/v2 state migrates additively, with its history, active workout and settings retained. IndexedDB stores/versions remain unchanged; revision checks and atomic save/restore with recovery snapshots continue to apply.
