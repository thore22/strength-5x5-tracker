# Accessory swap policy

Researched 2026-11-07. These are product decisions inferred from movement roles and exercise descriptions, not scientifically validated equivalence pairs. Loading, difficulty and muscle emphasis differ; each exercise retains its stable ID and independent progression.

Only the original accessory in the active A/B session determines the eligible group. Program edits, the other template, and repeated swaps cannot broaden that group. Exclude duplicates, core lifts, unclassified custom IDs, and built-in IDs whose equipment was changed. User-edited names and descriptions keep their exercise identity.

## Curated groups

| Accessories                                            | Allowed group                    | Basis and limits                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| ------------------------------------------------------ | -------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Barbell Curl, Dumbbell Curl, Hammer Curl               | Each other                       | Elbow-flexion accessory; grip and loading differ. Dumbbell load is per hand. [ACE barbell curl](https://www.acefitness.org/resources/everyone/exercise-library/70/bicep-curl/), [ACE hammer curl](https://www.acefitness.org/resources/everyone/exercise-library/10/hammer-curl/).                                                                                                                                                                                                               |
| Pull-ups, Chin-ups                                     | Each other                       | Vertical pulling with different grips. [ACE's workout builder](https://www.acefitness.org/continuing-education/certified/december-2024/8763/the-ace-body-weight-workout-builder/) places both in its pulling column.                                                                                                                                                                                                                                                                             |
| Dips, Triceps Extension, Skull Crusher                 | Each other                       | The user explicitly accepts extensions and skull crushers for the dips accessory slot. This preserves triceps work while omitting the chest work of dips; the UI states that difference. [ACE's triceps study](https://www.acefitness.org/certifiednewsarticle/3008/ace-study-identifies-best-triceps-exercises/) describes dips, push-downs and lying barbell extensions; it does not establish equivalent compound pressing or transferable loads.                                             |
| Hanging Leg Raise, Hanging Knee Raise                  | Each other                       | Hanging hip flexion/anterior-core work; straight legs change leverage and difficulty. [International Taekwon-Do exercise essay](https://members.itkd.co.nz/reference/essays/2020/Gr152_19080_Bowler-parkin_attessay_Essay.pdf), [St Paul's exercise appendix](https://www.stpaul.gov/sites/default/files/Media%20Root/Human%20Resources/Preparing%20for%20the%20SPFD%20Physical%20Performance%20Test%20Download%20Part%204%20-%20Exercise%20Appendix.pdf). Both still require a hanging station. |
| Plank, Ab Wheel                                        | Each other                       | Trunk bracing/anti-extension role; rollouts are more demanding. Separate seconds and rep targets. [ACE front plank](https://www.acefitness.org/resources/everyone/exercise-library/32/front-plank/), [NSCA Coach rowing strength article](https://rowingstronger.com/wp-content/uploads/2020/11/Parts-1-3-NSCA-Coach-Trilogy-11110823.pdf). Do not group with hanging raises.                                                                                                                    |
| Romanian Deadlift, Back Extension                      | Each other, accessory slots only | Hip-extension accessory using the catalog's hip-hinge Roman-chair back extension, not seated lumbar extension. [Andersen et al. 2021](https://doi.org/10.52082/jssm.2021.181) compare their differing activation and torque profiles. Acute EMG does not establish equal long-term results.                                                                                                                                                                                                      |
| Dumbbell Lateral Raise, Single-arm Cable Lateral Raise | Each other                       | Shoulder abduction/side-shoulder role with different resistance profiles. [ACE's cable lateral raise](https://www.acefitness.org/resources/everyone/exercise-library/354/single-arm-lateral-raise/) describes raising the arm to the side. Do both sides before logging one cable set; record the one-arm stack load. No face-pull crossover.                                                                                                                                                    |
| Face Pull, Dumbbell Reverse Fly                        | Each other                       | Rear-shoulder/upper-back accessory alternative, inferred from the overlap described by [NASM face pull](https://www.nasm.org/resource-center/exercise-library/face-pull) and [Mayo Clinic reverse fly](https://www.mayoclinic.org/healthy-lifestyle/fitness/multimedia/reverse-fly/vid-20084679). Different elbow motion and shoulder rotation; a reverse fly does not reproduce every face-pull component. Log weight per dumbbell.                                                             |
| Calf Raise, Standing Dumbbell Calf Raise               | Each other                       | Calf-raise/ankle plantar-flexion role. [ACE's calf library](https://www.acefitness.org/resources/everyone/exercise-library/body-part/legs-calves-and-shins/) includes machine and free-weight variants; [Mayo Clinic](https://www.mayoclinic.org/healthy-lifestyle/fitness/multimedia/calf-raise/vid-20084681) describes standing with a dumbbell in each hand. Standing versus seated versions differ in muscle emphasis. Log weight per dumbbell, not combined load or body mass.              |

The newly included entries are `cable-lateral`, `db-reverse-fly`, and `db-calf-raise`. Every built-in accessory now belongs to a group with an alternative. A particular session may still have no available alternative if its candidates are already in the workout or their equipment definitions have been customized.

## Replacement prescriptions

These are app defaults, not prescriptions mandated by the sources. They apply when selecting a replacement; returning to the original restores its captured custom prescription. Keep the original slot's rest period. Do not import a prescription from the other workout or mutate either template.

| Replacement                                               | Sets × target     | Progression                    |
| --------------------------------------------------------- | ----------------- | ------------------------------ |
| Curls; triceps extension; skull crusher                   | 3 × 8–12 reps     | Double progression suggestions |
| Dips                                                      | 3 × 6–10 reps     | Double progression suggestions |
| Pull-ups; chin-ups                                        | 3 × 5–10 reps     | Double progression suggestions |
| Hanging leg/knee raise                                    | 3 × 8–15 reps     | Manual; no added load          |
| Plank                                                     | 3 × 20–40 seconds | Manual; no added load          |
| Ab wheel                                                  | 3 × 6–10 reps     | Manual; no added load          |
| Romanian deadlift                                         | 2 × 8–10 reps     | Double progression suggestions |
| Back extension                                            | 2 × 8–12 reps     | Double progression suggestions |
| Dumbbell/cable lateral raise; machine/dumbbell calf raise | 3 × 10–15 reps    | Double progression suggestions |
| Face pull; dumbbell reverse fly                           | 3 × 12–15 reps    | Double progression suggestions |

Loaded alternatives use their own saved target when previously performed, with explicit confirmation. Without previous performance, require an entered starting load; never reuse the original's weight or assume a catalog starting value is suitable. The dialog displays prior reps and individual set loads.

## Information during a session

Only active accessory cards have a small question-mark button beside the exercise name, with a 44px touch target and an accessible label. It opens a modal sheet with the session's saved description, equipment/load convention, and Google, Google Images and YouTube technique-search links. Searches open a new tab and need internet; the saved description works offline. Program uses the same link/load-note component. The popup stays available while paused or after sets are logged and never edits the workout. After a swap, it shows the replacement's snapshot. Both sheets contain keyboard focus, support Escape and return focus to their opening button.

## Storage

State/backup v3 retains the original exercise, prescription and load in optional `SessionLift.replaced` metadata. Existing v1/v2 state migrates additively without dropping training data. The catalog extension adds only the three missing definitions and corresponding independent progression entries to validated v1/v2/v3 states and supported backups; existing definitions, user edits, counters, templates and active/completed snapshots remain unchanged. It is idempotent and does not repair invalid references. Fully populated 1000-entry custom libraries retain the existing limit rather than losing entries to make room. IndexedDB stores and versions are unchanged. Save/restore remain atomic with revision checks and recovery snapshots; older backup checksums are verified before catalog additions.
